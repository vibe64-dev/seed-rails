# Blueprint

A small notes application. Visitors open a home page that lists the most recent
notes, newest first, and offers a form to add one. A saved note appears at the
top of the list straight away; an empty or overlong note is refused with an
explanation and the visitor's text is kept for correction.

Anyone can read and add notes without an account. A person with an account can
sign in with an email address and password, sees which account is signed in on
every page, and can sign out. A forgotten password can be reset through an
emailed link. Development starts with one ready account so sign-in can be tried
immediately.

Operators can check whether the application is available.
